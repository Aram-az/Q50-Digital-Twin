# EPK device certificate

`obu_cert.pem` is the **public-only** compatibility certificate published in:
https://github.com/bugjosh/appgarage-dash/blob/main/keys/obu_cert.pem

Source AppGarage Dash: MIT license, copyright to respective upstream contributors.
No private device key or vehicle secret is included. A public certificate does
not guarantee compatibility with your own firmware revision.

The keystore generated by `build.ps1` is **your own developer APK signing key**,
not an Infiniti device private key. It lives in `native-app/signing/` (gitignored).
Backup this keystore privately; losing it will prevent in-place updates under
that app ID on a package manager enforcing signature consistency.
